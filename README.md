# 321QT 新約靈修會主

321 PWA built from the 靈修會主 lessons (馬太福音、馬可福音、路加福音、約翰福音、使徒行傳; 795 lessons).
Languages: 繁體 / 简体 / English (English lesson text is being translated in batches; `pend:1` marks untranslated lessons).

- `data/{zh,zs,en}-NN.json` 50 lessons per file, `data/idx-*.json` indexes
- `tools/lessons_zh.json` Chinese source of truth; `tools/pending_en.json` lessons awaiting English translation
- `tools/make_data.py` regenerates data from `lessons_zh.json`

Pages: https://spch321-sudo.github.io/321devotion/
